## ⚙️ Cómo ejecutar este Portafolio localmente

Este proyecto está construido con **HTML5 puro** y **Tailwind CSS v3** compilado localmente. No utiliza frameworks pesados de JavaScript para mantener una carga ultrarrápida.

### Prerrequisitos
- [Node.js](https://nodejs.org/) instalado en tu máquina.

### Pasos
1. Cloná este repositorio:
   ```bash
   git clone [https://github.com/materivas/portfolio-2026.git](https://github.com/materivas/portfolio-2026.git)
Navegá a la carpeta del proyecto:

Bash
cd portfolio-2026
Instalá las dependencias de desarrollo (Tailwind CSS y sus plugins):

Bash
npm install
Ejecutá el compilador de Tailwind en modo "watch":

Bash
npx tailwindcss -i ./src/css/input.css -o ./src/css/output.css --watch
Abrí el archivo index.html en tu navegador de preferencia o usá una extensión como Live Server en VS Code.
